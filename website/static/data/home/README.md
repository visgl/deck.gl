# Landing page taxi data

The samples are unchanged from the [deck.gl-data website fixtures](https://github.com/visgl/deck.gl-data/tree/a85a4ab3c578e36af1decfd0a46fb713459301bf/website). See the accompanying LICENSE for the upstream MIT notice.

- Taxi trips come from the [New York City Taxi and Limousine Commission](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page).
- Building footprints come from [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) via [Mapzen](https://mapzen.com/). The building data is available under the [Open Database License](https://opendatacommons.org/licenses/odbl/1-0/).
