# Website map style notices

`deck-light.json` is adapted from OpenFreeMap Positron; `deck-dark.json` is adapted
from OpenFreeMap Dark. Both assets have their symbol layers removed and are renamed.
The sources, sprites, and glyphs use OpenFreeMap hosting.

Sources:
- https://github.com/hyperknot/openfreemap-styles
- https://github.com/openmaptiles/positron-gl-style
- https://github.com/openmaptiles/dark-matter-gl-style

The following upstream notices apply to both assets.

Products or services using maps derived from OpenMapTiles schema need to visibly
credit "OpenMapTiles.org" or reference "OpenMapTiles" with a link to
https://openmaptiles.org/.

For a browsable electronic map based on OpenMapTiles and OpenStreetMap data, the

[© OpenMapTiles](https://openmaptiles.org/)

description near the image, in the same fashion as if you cite a photograph.

by MapTiler AG (info@maptiler.com).
