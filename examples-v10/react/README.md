# @deck.gl/react examples

Standalone applications that render deck.gl with the `@deck.gl/react` renderer, each in its
framework's usual project layout. See the [`@deck.gl/react` docs](../../docs/get-started/using-with-react.md).

- **[Vite](./vite)**: a client-rendered app with an interleaved MapLibre map, layers as React
  components, and shared state between layers and DOM UI.
