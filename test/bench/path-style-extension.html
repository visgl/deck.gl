PathStyleExtension GPU benchmark

Uses WebGL2 timestamp queries around deck.gl render passes. Run on hardware; software adapters and virtualized browsers are not representative. Shader compilation, attribute generation, and timestamp-query readback are excluded from reported GPU durations. The benchmark rotates and reverses variant order to reduce ordering and thermal bias.

Offset-enabled variants use a zero offset so they measure the extension capability without changing screen coverage. CPU path-phase generation for 100K segments is measured on the CPU benchmark page; segment mode has no phase pass.

“Pass-only FPS” is 1000 / median GPU ms and is useful for comparing these isolated render passes; it is not whole-application FPS. The 60 Hz and 120 Hz columns show how much of those frame budgets the added time versus a plain PathLayer would consume.
